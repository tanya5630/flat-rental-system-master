1. Introduction

Unit testing was implemented for the Flat Rental System (LuxeFlats) backend to verify that individual services, domain logic, and validation methods operate correctly and reliably in complete isolation. JUnit 5 was used as the standard Java testing framework to structure and execute test suites, while Mockito was used to mock external dependencies — repositories, security utilities, and inter-service HTTP clients — without requiring a live MySQL database or network connectivity.

The complete suite covers successful core workflows, input validation, exception handling, role-based authorization, state-transition guards, token/JWT handling, and payment processing. A total of 78 test cases were executed across all four microservices, and all 78 test cases passed successfully (100% success rate).

1.1 Edge-Case Testing Rationale

  • Null or missing required fields (e.g. null email, null tenant ID, null payment method).
  • Malformed or invalid formats (e.g. an email address with no domain, an unsupported enum value).
  • Boundary and out-of-range values (e.g. negative or zero payment amounts, negative rent, zero/negative salary).
  • Temporal edge cases (e.g. a booking check-in date in the past, an expired JWT token).
  • Repeated or duplicate actions against terminal states (e.g. cancelling an already-cancelled booking, refunding an already-refunded payment).
